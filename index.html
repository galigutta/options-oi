How to add a symbol

  1. Confirm OCC has equity series: series-search?symbolType=U&symbol=TICKER.
  2. Add the ticker to watchlist.txt (or config.yaml) in open_interest.
  3. Run python oi.py TICKER (or python oi.py --watchlist).
  4. Copy snapshot/TICKER-* into data/TICKER/ on this Pages repo (index.csv, optional latest-summary.csv / latest-oi.csv / meta.json), and add the symbol to tickers.json.
  5. IV: AlphaQuery /stock/TICKER/volatility-option-statistics/30-day/iv-mean; if scrape fails, flat fallback in DEFAULT_VOLS.

Default watchlist (no ETFs): TSLA, NVDA, AAPL, AMZN, META, GOOGL, MSFT, AMD, NFLX, SPCX.
